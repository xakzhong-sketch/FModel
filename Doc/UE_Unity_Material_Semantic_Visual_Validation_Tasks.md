# UE Unity Material Semantic Visual Validation Tasks

Status: task breakdown for `UE_Unity_Material_Semantic_Visual_Validation_Plan.md`.

## Scope

Implement a post-material-restore semantic visual validation workflow for Unity 6 URP Deferred reconstructed shaders.

Primary goals:

- Export Unity semantic captures for restored materials.
- Compare captures against structured visual references and optional RenderDoc/UE semantic evidence.
- Generate compact AI-friendly validation reports.
- Let future Agents fix shader/module logic based on report-first evidence.

Do not modify RenderDoc/qrenderdoc. Do not make this part of material property restore Apply by default.

- Bundle docs can include compact visual validation report paths when present.
